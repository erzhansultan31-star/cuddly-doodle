# Telegram Audio Bot

Кез келген аудио файлды қабылдап, оны жаңа мұқаба фото (`placeholder.jpg`) мен
жаңа "әнші аты" (performer) мәнімен қайта жіберетін бот.

## 1. Файлдар
- `bot.py` — боттың негізгі коды
- `requirements.txt` — керекті кітапханалар
- `Procfile` — Railway/Render үшін іске қосу командасы
- `placeholder.jpg` — уақытша мұқаба сурет (кейін өз суретіңізге алмастырасыз)

## 2. Railway-ге орналастыру қадамдары

1. **GitHub-қа жүктеу**
   - github.com сайтында жаңа репозиторий ашыңыз (мысалы `telegram-audio-bot`).
   - Осы 4 файлды (`bot.py`, `requirements.txt`, `Procfile`, `placeholder.jpg`)
     сол репозиторийге жүктеңіз (Add file → Upload files).

2. **Railway-де жаңа жоба ашу**
   - https://railway.app сайтына GitHub аккаунтыңызбен кіріңіз.
   - "New Project" → "Deploy from GitHub repo" → жаңа ғана жасаған
     репозиторийді таңдаңыз.

3. **Environment Variables қосу**
   - Жоба ішінде "Variables" бөліміне өтіңіз.
   - Мына айнымалыны қосыңыз:
     - `BOT_TOKEN` = BotFather берген токеніңіз
   - Қаласаңыз, мынаны да қосуға болады (әнші атын өзгерту үшін):
     - `PERFORMER_NAME` = "Сіз қалаған мәтін"
   - Егер `PERFORMER_NAME` қоймасаңыз, әдепкі бойынша "Сенің атың осында"
     деген мәтін тұрады.

4. **Іске қосу**
   - Railway `Procfile`-ды көріп, өзі `python bot.py` командасын іске қосады.
   - "Deployments" бөлімінде логтан "Бот іске қосылды..." деген жазуды
     көрсеңіз — дайын.

5. **Тексеру**
   - Telegram-да ботыңызды тауып, кез келген аудио немесе mp3 жіберіп көріңіз.
   - Бот жаңа мұқаба + жаңа performer атымен қайтарады.

## 3. Кейін өзгерту

- **Мұқаба суретті ауыстыру:** `placeholder.jpg` файлын өз суретіңізбен
  алмастырып, репозиторийге қайта жүктесеңіз болды (Railway автоматты түрде
  қайта деплой етеді).
- **Мәтінді ауыстыру:** Railway-дегі `PERFORMER_NAME` айнымалысының мәнін
  өзгертіп сақтасаңыз жеткілікті, кодты қайта жазудың қажеті жоқ.

## 4. Локалды тестілеу (өз компьютерде)

```bash
pip install -r requirements.txt
export BOT_TOKEN="сіздің_токеніңіз"
export PERFORMER_NAME="Сіздің мәтініңіз"   # міндетті емес
python bot.py
```
