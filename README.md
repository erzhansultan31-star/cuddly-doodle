# Telegram Audio & Photo Bot

Кез келген аудио файлды қабылдап, оны жаңа мұқаба фото мен жаңа
"әнші аты" (performer) мәнімен қайта жіберетін, кез келген суретті
watermark-пен қайтаратын, әрі екеуін де автоматты түрде сіздің
Telegram каналыңызға жариялайтын бот.

## 1. Файлдар
- `bot.py` — боттың негізгі коды
- `requirements.txt` — керекті кітапханалар
- `Procfile` — Render/Railway үшін іске қосу командасы
- `runtime.txt` — Python нұсқасын бекітеді (3.11.9)
- `placeholder.jpg` — мұқаба сурет (өз суретіңізбен алмастырылған)
- `font.ttf` — watermark мен мұқаба жазуларына арналған шрифт (бумен бірге жүреді, серверде шрифт болмаса да жұмыс істейді)

## 2. Каналды дайындау (ЖАҢА)

1. Telegram-да өз каналыңызды ашыңыз.
2. Каналдың әкімшілері (Administrators) тізіміне ботыңызды қосыңыз:
   - Канал баптаулары → Administrators → Add Administrator → ботыңызды табыңыз.
   - Бот кем дегенде **"Post Messages"** құқығына ие болуы керек.
3. Канал ID-ін алыңыз:
   - Егер канал публикалық болса (мыс. `t.me/meningkanalym`) — ID ретінде
     `@meningkanalym` түрінде жазуға болады.
   - Егер канал жабық (private) болса, сандық ID керек (мыс. `-1001234567890`).
     Мұны алу үшін каналда бір хабарлама жіберіп, оны
     `@userinfobot` немесе `@getidsbot` ботына forward жасаңыз - ол
     каналдың сандық ID-ін көрсетеді.

## 3. Render-де Environment Variables

Осы айнымалыларды Render-дегі "Environment" бөліміне қосыңыз:

| Key | Мысал мән | Сипаттамасы |
|---|---|---|
| `BOT_TOKEN` | `7703336537:AAG7...` | BotFather берген токен |
| `CHANNEL_ID` | `@meningkanalym` немесе `-1001234567890` | Каналдың ID-і (МІНДЕТТІ) |
| `PERFORMER_NAME` | `Сіздің брендіңіз` | Аудиода көрсетілетін "әнші аты" |
| `AUTHOR_CAPTION` | `🎵 Жаңа ән SharapatMuzz-тен` | Каналдағы хабарламаның үстіндегі тұрақты мәтін |
| `WATERMARK_TEXT` | `@sharapatmuzz` | Суреттердің үстіне қойылатын watermark мәтіні |

`PERFORMER_NAME` мен `AUTHOR_CAPTION` қоспасаңыз, әдепкі мәндер қолданылады.
`CHANNEL_ID` міндетті түрде қажет — қоймасаңыз, бот қатемен тоқтайды.

## 4. Іске қосу тәртібі

**Аудио үшін:**
1. Пайдаланушы ботқа аудио жібереді.
2. Бот мұқаба мен performer атын өзгертіп, пайдаланушыға қайта жібереді.
3. Дәл сол өңделген аудио каналыңызға автоматты түрде жарияланады
   (`AUTHOR_CAPTION` мәтінімен).

**Сурет үшін (ЖАҢА):**
1. Пайдаланушы ботқа сурет жібереді.
2. Бот суреттің төменгі жағына, ортасына, орташа өлшемде және
   күңгірт (жартылай мөлдір) `WATERMARK_TEXT` мәтінін қояды.
3. Watermark қойылған сурет пайдаланушыға қайтарылады және
   каналыңызға автоматты түрде жарияланады (`AUTHOR_CAPTION` мәтінімен).

⚠️ **Ескерту:** бот публикалық болғандықтан, кез келген адам аудио жіберіп,
ол автоматты түрде каналыңызда жарияла алады. Егер келешекте модерация
(алдымен растау) қажет болса, айтыңыз — осы логиканы кез келген уақытта
өзгертуге болады.

## 5. Railway-ге орналастыру қадамдары

1. **GitHub-қа жүктеу**
   - github.com сайтында жаңа репозиторий ашыңыз (мысалы `telegram-audio-bot`).
   - Барлық файлдарды (`bot.py`, `requirements.txt`, `Procfile`, `runtime.txt`,
     `placeholder.jpg`, `font.ttf`) сол репозиторийге жүктеңіз.

2. **Render/Railway-де жаңа жоба ашу**
   - Тиісті сайтта GitHub аккаунтыңызбен кіріп, репозиторийді таңдаңыз.

3. **Environment Variables қосу** (жоғарыдағы кестені қараңыз)

4. **Іске қосу**
   - Хостинг `Procfile`-ды көріп, өзі `python bot.py` командасын іске қосады.
   - Логтан "Бот іске қосылды..." деген жазуды көрсеңіз — дайын.

5. **Тексеру**
   - Ботыңызға mp3 жіберіп көріңіз.
   - Бот жаңа мұқаба + performer атымен қайтарады, әрі сол хабарлама каналыңызда
     да пайда болуы керек.

## 6. Кейін өзгерту

- **Мұқаба суретті ауыстыру:** `placeholder.jpg` файлын алмастырып, GitHub-қа
  қайта жүктесеңіз болды.
- **Мәтіндерді ауыстыру:** Render-дегі `PERFORMER_NAME` мен `AUTHOR_CAPTION`
  айнымалыларының мәнін өзгертіп сақтасаңыз жеткілікті.
- **Каналды ауыстыру:** `CHANNEL_ID` айнымалысын жаңа канал ID-іне өзгертіңіз.

## 7. Локалды тестілеу (өз компьютерде)

```bash
pip install -r requirements.txt
export BOT_TOKEN="сіздің_токеніңіз"
export CHANNEL_ID="@meningkanalym"
export PERFORMER_NAME="Сіздің мәтініңіз"   # міндетті емес
export AUTHOR_CAPTION="Тұрақты мәтініңіз"   # міндетті емес
python bot.py
```
